# Skills de Material Estudio

Fuentes instalables de las Skills de Material Estudio, alojadas en este repositorio. No requieren paquete ni instalador npm: Codex puede instalarlas directamente desde GitHub mediante la Skill preinstalada `skill-installer`.

Incluye:

- `material-estudio-flujo`
- `material-estudio-materiales`
- `material-estudio-planificar`
- `material-estudio-perfil-examen`
- `material-estudio-practicar`

Para instalar una o varias, pide a Codex que use `skill-installer` con el repositorio `otromas1234/material-asignaturas` y las rutas `skills/<nombre-de-skill>`. Ejemplo: «Instala `material-estudio-practicar` desde `otromas1234/material-asignaturas`, ruta `skills/material-estudio-practicar`». El instalador usa su destino estándar de Codex; si esta instalación usa una ruta personalizada, indícala explícitamente.
